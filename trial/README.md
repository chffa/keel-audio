# Проба голосов Keel

Слова и формы юнитов A1 и предложения заданий A1 разными голосами — для сравнения в отладочной версии Keel
(настройка «Голос озвучки»). Обработка та же, что у основных записей в audio/. Имя файла — хеш произносимого текста.

- vesta (с точкой в конце текста), mari, liivika — синтез речи «Neurokõne» Тартуского университета (TartuNLP).
- chirp-… — голоса Google Cloud Text-to-Speech Chirp 3 HD (et-EE).

Voice trial for the Keel debug build: the same texts in other voices. Files are named after a hash of the text.
