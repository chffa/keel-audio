# keel-audio

Записи озвучки для веб-версии [Keel](https://keel.chiffaa.workers.dev) — эстонские слова и их формы,
фразы, вопросы и предложения заданий. Синтез речи «Neurokõne» Тартуского университета
([TartuNLP](https://tartunlp.ai)). Файлы раздаёт GitHub Pages; имя файла — хеш произносимого текста.
Сюда их выкладывает `npm run audio:publish` из репозитория приложения — руками ничего не правится.

Audio for the Keel web app (Estonian words for Russian speakers), synthesized with TartuNLP Neurokõne.
Served by GitHub Pages; each file is named after a hash of the text it speaks.
